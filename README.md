# React Auth System with FPL Integration

A React-based web application featuring user authentication, real-time chat, Fantasy Premier League (FPL) integration, and activity feed functionality.

## 🚀 Features

- **Authentication**
  - Supabase-based authentication
  - Protected routes
  - User profile management

- **Fantasy Premier League Integration**
  - Live FPL data integration
  - Personal team overview
  - League standings
  - Performance history
  - Real-time updates

- **Chat System**
  - Real-time messaging
  - Thread-based conversations
  - User avatars
  - Message history

- **Activity Feed**
  - Real-time updates
  - Multiple event types (Chat, FPL, Profile)
  - Filtered views
  - Infinite scroll

## 🛠 Tech Stack

- **Frontend Framework**: React 18
- **Type System**: TypeScript
- **Build Tool**: Vite
- **Authentication**: Supabase Auth
- **Database**: Supabase PostgreSQL
- **Real-time**: Supabase Realtime
- **Styling**: TailwindCSS
- **Testing**: Vitest
- **Charts**: Chart.js
- **Routing**: React Router v6
